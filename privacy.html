Privacy Policy — AQA Pipeline

Last updated: 12 November 2026

AQA Pipeline is a private tool used only by the owner of the YouTube channel "Behind the Alarm" to upload that channel's own videos and to update that channel's own settings. It is not offered to the public.

What it accesses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos, set thumbnails and captions, manage playlists, and update the channel description, keywords and banner of the owner's channel.

What it stores

It stores one OAuth refresh token as an encrypted secret in the owner's own GitHub repository settings and/or on the owner's computer. It does not collect, store, sell or share any data about other people, and it does not use YouTube data for advertising or analytics.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: via the contact options on the Behind the Alarm channel.
